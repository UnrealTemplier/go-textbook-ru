# CHANGELOG html-textbook-engine

У каждой версии — пометка «меняет вывод»: изменится ли HTML книги после `engine.sync`.

## 1.2.0-dev (в разработке, выделяется из go-textbook)

Меняет вывод: да (этап А3; по каждому изменению — строка ниже и реестр book/content-exceptions.txt книги).

Изменения вывода (А3):
- А3а: wikilinks и клише не трогают строки кода (маска); ссылки больше не вставляются внутрь fenced-кода.
- А3а′: выноски — плейсхолдеры, тело рендерится отдельно (wikilinks по маске тела); `[[…]]` в inline-коде: найденная цель — ссылка `<a class="wikilink"><code>…</code></a>`, иначе код буквально. Пустые строки вокруг `<aside>` изменились.
- А3б: гибридный сайдбар (`[navigation] mode = "hybrid"`): в HTML только текущий модуль, полное дерево — `assets/nav-data.js`.
- А3в: Mermaid, KaTeX и Prism подключаются только на страницах, где нужны (`[features] conditional_scripts`).
- А3г: иконка кнопки копирования — `<use href="#icon-copy">` из спрайта на странице.
- А3д: повторяющиеся `id` заголовков получают `-2`, `-3`, ….
- А3е: разметка в заголовках H2–H4 обрабатывается Python-Markdown, `id` по TOC ставит treeprocessor; хвост `#` экранируется во всех заголовках.
- А3и: `[math] protect` — разделители формул из списка не обрабатываются Python-Markdown (в go-textbook — `\(` и `\[`).
- А3к: при `title_source = "filename"` первый H1 тела, побуквенно равный заголовку страницы, убирается (U14). Остальные пары — в реестре `python -m engine.tools.title_duplicates`.
- А3м: разметка модального окна Mermaid выводится только на страницах с диаграммами (вместе с `mermaid.min.js`).
- А3л: `[markdown] obsidian_lists` — списки Obsidian/CommonMark (U17): список сразу после абзаца, вложенность 2–3 пробела, цитата в пункте, списки в обычных цитатах.
- А3з: `[markdown] indented_fences` — ограда с отступом внутри пункта списка становится блоком кода (U13); язык блока кода — `[\w#.+-]+` (`c++`, `c#`).

Без изменения вывода (А1–А2):

- Пакет `engine/` вместо `builder/`: `python -m engine.build`, `python -m engine.audit`.
- `book.toml`: версия, `storage_prefix`, slug, канонические названия, клише, выноски, время чтения, брендинг и тексты страниц, `[markdown]`, `[math]`, `[layout]`, `[strings]`.
- Словарь строк интерфейса `engine/strings/ru.toml`.
- Рекурсивный сканер: дерево любой глубины, ошибки вместо тихих потерь файлов, `title_source = "h1"`, индексные файлы каталогов.
- Расширения Python-Markdown за флагами: списки Obsidian, ограды с отступом в списках, защита формул; заголовки и выноски-плейсхолдеры (подключаются в А3).
- Частичные шаблоны `engine/templates/` и переопределения книги (`book/overrides/`), хуки `book/hooks.py`, `extra.css`/`extra.js`.
- Контрольные суммы ядра (`python -m engine.checksums`).
