Списки и код

Списки в стиле Obsidian

Список может идти сразу за строкой текста:

  • первый пункт
  • второй пункт
    • вложенный пункт (отступ 2 пробела)
    • ещё один

Нумерованный список с кодом внутри пункта:

  1. Объявление переменной:

    Go 
    var name string = "Go"

    Пояснение после кода остаётся в пункте.

  2. Короткое объявление := — только внутри функций.
