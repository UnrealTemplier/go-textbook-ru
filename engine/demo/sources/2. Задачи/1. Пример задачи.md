# Пример задачи: длина массива

## Условие
Объяви массив из 5 целых чисел и выведи его длину.

## Решение по шагам
1. Создаём массив `[5]int{1, 2, 3, 4, 5}`.
2. Вызываем `len()`.

## Код решения
**`main.go`**
```go
package main

import "fmt"

func main() {
	a := [5]int{1, 2, 3, 4, 5}
	fmt.Println(len(a))
}
```
