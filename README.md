## 🌟 Ключевые особенности портала

* 📦 **Полный Offline First:** Учебник собран как 100% статический веб-портал. Никаких внешних CDN, сетевых зависимостей, npm, node.js или бэкенд-серверов. Портал безупречно работает **локально прямо из файловой системы по протоколу `file:///`**, на флешке в автономном контуре или на любом статическом хостинге (GitHub Pages, Nginx, S3).
* 🎨 **Трёхтемная дизайн-система и инженерная эстетика:**
  * 🌑 **Dark (по умолчанию):** глубокая сдержанная тёмная палитра (`#0b0f19` / `#0f172a` / `#131d33`) с акцентами indigo и sky для минимальной зрительной нагрузки при разработке;
  * 📄 **Paper:** эстетика классического университетского справочника Bell Labs на тёплой бумаге (`#faf9f6` / `#ffffff`);
  * ☀️ **Light:** современная чистая инженерная документация в нейтральных холодных тонах slate (`#f8fafc` / `#ffffff`).
  * **Единый плавающий переключатель:** вынесен в правый нижний угол экрана (`.floating-theme-switcher`, icon-only с SVG-иконками и подсказкой), мгновенно переключает темы без перезагрузки страниц с сохранением выбора в `localStorage` и защитой от мигания (anti-flicker).
  * **Инженерная типографика:** локально поставляемые математические шрифты KaTeX, адаптивная подсветка кода Prism.js (Go, C, ASM, SQL, Bash, Python, YAML, JSON) под каждую тему с копированием в буфер в один клик.
* 📊 **2 486 цветных диаграмм Mermaid:** Архитектура систем, жизненные циклы процессов, графы состояний и алгоритмы визуализированы через наглядные схемы. Все диаграммы адаптируются под активную тему оформления (Dark, Paper, Light) через семантические CSS-токены, поддерживают модальный полноэкранный просмотр и интерактивный зум.
* 🔍 **Мгновенный живой поиск:** Клиентский полнотекстовый фильтр по заголовкам, ключевым словам и темам всех 1 413 статей с подсветкой результатов.
* 📱 **Двухуровневая ширина и адаптивный интерфейс:**
  * **Layout Refinement:** широкие технические блоки (диаграммы Mermaid, таблицы данных, листинги кода, выноски) масштабируются до ширины `1040px`, предотвращая горизонтальный скролл;
  * **Комфортное чтение:** колонка обычной прозы ограничена шириной `880px` с межстрочным интервалом `1.75` для оптимальной эргономики многочасового чтения;
  * **Двухпанельный лейаут:** регулируемый сайдбар (drag-to-resize) с сохранением ширины в `localStorage`, счётчиком статей, чипом версии (`v1.1.0`), древовидным аккордеоном, активной подсветкой текущего раздела, хлебными крошками и пагинацией «← Назад / Вперед →».
* 🛡 **Кроссплатформенность и эталонная ссылочная надёжность:** 100% совместимость путей и имен файлов с Windows NTFS, macOS APFS и Linux; безупречная ссылочная целостность в аудите: **0 broken links, 0 missing anchors, 0 mermaid errors, 0 filesystem errors**.

## 🔬 Анализ используемых версий Go (Go 1.22 — 1.27)

Энциклопедия создавалась с прицелом на долгосрочную актуальность и опережающий инженерный горизонт:

1. **Сквозной фундамент (Go 1.22 – 1.23):**  
   Используется **во всех 22 модулях учебника**. В примерах кода и архитектурных разборах задействованы:
   - Исправленная семантика переменных цикла `for` (Go 1.22, устранение data race с замыканиями);
   - Пользовательские итераторы и функции обхода (range over func types);
   - Новые стандартные пакеты `slices`, `maps`, `cmp`, `math/rand/v2`;
   - Структурированное логирование `log/slog` и Profile-Guided Optimization (PGO).

2. **Современный рантайм (Go 1.24):**  
   - **Модули 20 и 21 (DSA & LeetCode):** Детально разобрана революция ассоциативных массивов — замена классической архитектуры `hmap/bmap` на **Swiss Tables** (разработка Google, 8-слотовые группы `MapGroupSlots = 8` с 64-битным контрольным словом `ctrlGroup` и параллельной фильтрацией через SWAR/SIMD);
   - **Модули 17, 21 и 22:** Директорийно-ограниченный доступ к файловой системе `os.Root`, квантово-устойчивый гибридный обмен ключами `X25519MLKEM768` (FIPS 203, `crypto/mlkem`) по умолчанию в TLS 1.3, generic type aliases.

3. **Эволюция современного Go (Go 1.25 – 1.27):**  
   Глубоко систематизирована в **Модуле 22 (лекции 23–28)** в виде блока из 31 актуального вопроса для технических интервью:
   - **Go 1.25:** Стабилизация пакета `testing/synctest` для детерминированного тестирования конкурентного кода без искусственных `time.Sleep` (впервые появился как эксперимент в Go 1.24);
   - **Go 1.26:** Пакет `crypto/hpke` (Hybrid Public Key Encryption, RFC 9180) как криптографический фундамент для протоколов TLS ECH и MLS;
   - **Go 1.27:** Внедрение стандарта NIST FIPS 204 — квантово-устойчивых цифровых подписей на решетках `crypto/mldsa` (Dilithium) в X.509 и TLS 1.3, поддержка generic-методов у конкретных типов (структур).

## 🛠 Техническое устройство портала

Веб-учебник генерируется кастомным легковесным SSG-генератором на чистом Python, спроектированным по принципам простоты и надежности Unix:

```text
go-textbook/
├── sources/             # Единый источник правды содержания (SSOT): 1413 Markdown-статей
├── builder/             # Движок генератора и инструменты QA
│   ├── build_all.py     # Главный оркестратор компиляции (флаги --all, --module, --pilot)
│   ├── scanner.py       # Сканирование источников, wikilinks-резолвер, канонизация якорей
│   ├── converter.py     # AST-конвертер Markdown -> HTML5, Callouts, автосанитизация Mermaid
│   ├── template.py      # HTML5 каркас, семантическая разметка, KaTeX, сайдбар, TOC
│   ├── audit_all.py     # Сквозной QA-аудитор (ссылки, анкоры, Mermaid, кроссплатформенность)
│   ├── verify_editorial.py # Инструмент контроля авторской редактуры ДО и ПОСЛЕ
│   └── assets/          # Исходные ассеты: style.css (дизайн-токены), main.js, вендоры
├── dist/                # Готовый скомпилированный сайт (1414 HTML страниц + ассеты)
├── AGENTS.md            # Архитектурный регламент и канонический источник версии (SSOT для build)
├── favicon.ico / .svg   # Иконки портала
└── README.md            # Публичное руководство и витрина проекта
```

### Преимущества архитектуры

## 🚀 Как пользоваться порталом

### Для читателей и инженеров

#### Вариант 1: Онлайн-версия на GitHub Pages
Портал опубликован и доступен онлайн:  
👉 **[https://unrealtemplier.github.io/go-textbook-ru/](https://unrealtemplier.github.io/go-textbook-ru/)**

#### Вариант 2: Мгновенный просмотр локально (Offline First — без установки чего-либо)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/UnrealTemplier/go-textbook-ru.git
   cd go-textbook-ru
   ```
2. Откройте файл `dist/index.html` в любом браузере:
   * **Linux:** `xdg-open dist/index.html`
   * **macOS:** `open dist/index.html`
   * **Windows:** двойной клик по `dist/index.html` или `start dist/index.html`

Всё работает прямо из коробки по протоколу `file:///`.

#### Вариант 3: Локальный веб-сервер
Если вы предпочитаете открывать портал через локальный веб-сервер:
```bash
python3 -m http.server 8080 -d dist
```
После чего перейдите в браузере по адресу: [http://localhost:8080](http://localhost:8080).

#### Вариант 4: Собственный хостинг
Директория `dist/` готова к развертыванию на любой статической платформе:
* **GitHub Pages:** автоматический деплой каталога `/dist` через GitHub Actions;
* **Nginx:** конфигурация `root /path/to/go-textbook-ru/dist; index index.html;`.

### 🌟 Что нового в релизе v1.1.0

Релиз **v1.1.0** развивает релизный baseline содержания `v1.0.2` (в котором была завершена полная авторская вычитка всех 22 модулей) и фокусируется на комплексном улучшении пользовательского интерфейса, надёжности и централизации инженерных стандартов:

1. **Трёхтемная дизайн-система (Three-Theme System):**
   * Внедрена единая система семантических CSS-токенов с тремя темами: **Dark** (глубокая ночная палитра, установлена темой по умолчанию), **Paper** (тёплая университетская эстетика книги на бумаге) и **Light** (современная чистая документация slate).
   * Выбор темы сохраняется в `localStorage` с защитой от мигания (anti-flicker script).
2. **Единый плавающий переключатель темы (Floating Theme Switcher):**
   * Переключатель вынесен из сайдбара в круглую кнопку в правом нижнем углу экрана (`.floating-theme-switcher`).
   * Icon-only интерфейс с SVG-иконками (документ, солнце, луна), тултипом и циклическим переключением без перезагрузки страниц.
3. **Темизация кода и диаграмм:**
   * Подсветка Prism.js переведена на собственные семантические токены без внешних vendor CSS файлов.
   * Диаграммы Mermaid 10.9.1 динамически адаптируются под активную тему через семантические CSS-селекторы с `!important` и бесшовно перерисовываются при смене темы на клиенте.
4. **Двухуровневая ширина контента (Layout Refinement):**
   * Ширина контейнера статьи и технических элементов (диаграммы Mermaid, таблицы данных, листинги кода, выноски) расширена до `1040px` (`--max-content-width`), предотвращая горизонтальный скролл.
   * Текстовая колонка прозы оптимизирована до `880px` (`--prose-max-width`) для сохранения идеальной эргономики длительного чтения.
5. **Сквозной QA-харденинг и ссылочная целостность:**
   * Устранены 299 исторических предупреждений о ненайденных анкорах: внедрена каноническая нормализация `slugify(..., max_length=80)` с предварительной очисткой Markdown-разметки.
   * Удалена небезопасная эвристика неточного угадывания (`suffix matching fallback`).
   * Текущий базовый срез: **0 broken links, 0 missing anchors, 0 mermaid errors, 0 filesystem errors**.
6. **Централизация метаданных версии и чистка тулинга:**
   * Канонический источник версии проекта строго централизован в `AGENTS.md` (§ 1.4) с автоматическим считыванием сборщиком в шапку главной страницы (`.hero-version`) и футер сайдбара (`.sidebar-version`).
   * Устаревший визуальный бейдж `Offline First` удален из сайдбара (принцип сохранен на архитектурном уровне).
   * Удалена устаревшая утилита миграции `builder/colorize_mermaid.py`.
