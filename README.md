## 🌟 Ключевые особенности портала

* 📦 **Полный Offline First:** Учебник собран как 100% статический веб-портал. Никаких внешних CDN, сетевых зависимостей, npm, node.js или бэкенд-серверов. Портал безупречно работает **локально прямо из файловой системы по протоколу `file:///`**, на флешке в самолете или на любом статическом хостинге (GitHub Pages, Cloudflare Pages, Nginx).
* 🎨 **Инженерная эстетика (дизайн Go Workout):** Глубокая тёмная палитра (`#0b0f19` / `#0f172a` / `#131d33`), акценты Indigo и Sky, комфортная типографика (Google Fonts Roboto, моноширинный код JetBrains Mono / Cascadia Code), формулы на KaTeX и подсветка кода Prism.js (Go, C, ASM, SQL, Bash, Python, YAML, JSON) с копированием в буфер в один клик.
* 📊 **2 486 цветных диаграмм Mermaid:** Архитектура систем, жизненные циклы процессов, графы состояний и алгоритмы визуализированы через наглядные схемы с обязательной тёмной семантической палитрой (белый контрастный текст `#f8fafc`).
* 🔍 **Мгновенный живой поиск:** Клиентский полнотекстовый фильтр по заголовкам, ключевым словам и темам всех 1 413 статей с подсветкой результатов.
* 📱 **Двухпанельный лейаут:** Регулируемый сайдбар (drag-to-resize) с запоминанием ширины в `localStorage`, древовидный аккордеон, активная подсветка текущего раздела, хлебные крошки и пагинация «← Назад / Вперед →».
* 🛡 **Кроссплатформенность файловой системы:** 100% совместимость путей и имен файлов с Windows NTFS, macOS APFS и Linux (отсутствие двоеточий, зарезервированных имен DOS и регистрозависимых коллизий).

## 🔬 Анализ используемых версий Go (Go 1.22 — 1.27)

Энциклопедия создавалась с прицелом на долгосрочную актуальность и опережающий инженерный горизонт:

1. **Сквозной фундамент (Go 1.22 – 1.23):**  
   Используется **во всех 22 модулях учебника**. В примерах кода и архитектурных разборах задействованы:
   - Исправленная семантика переменных цикла `for` (Go 1.22, устранение data race с замыканиями);
   - Пользовательские итераторы и функции обхода (range over func types);
   - Новые стандартные пакеты `slices`, `maps`, `cmp`, `math/rand/v2`;
   - Структурированное логирование `log/slog` и Profile-Guided Optimization (PGO).

2. **Современный рантайм (Go 1.24):**  
   - **Модуль 20 и 21 (DSA & LeetCode):** Детально разобрана революция ассоциативных массивов — замена классической архитектуры `hmap/bmap` на **Swiss Tables** (разработка Google, 16-слотовые группы с контрольными байтами `ctrl byte` и параллельной SIMD/SWAR фильтрацией за 1 такт CPU);
   - **Модули 17, 21 и 22:** Изоляция файловой системы `os.Root`, квантово-устойчивый гибридный обмен ключами `X25519Kyber768` в TLS 1.3, generic type aliases.

3. **Горизонт будущего (Go 1.25 – 1.27):**  
   Глубоко систематизирован в **Модуле 22 (лекции 23–28)** в виде блока из 31 актуального вопроса для технических интервью:
   - **Go 1.25:** Стабилизация пакета `testing/synctest` для детерминированного моментального тестирования конкурентного кода без вызовов `time.Sleep`;
   - **Go 1.26:** Пакет `crypto/hpke` (Hybrid Public Key Encryption, RFC 9180) для протоколов TLS ECH и MLS;
   - **Go 1.27:** Внедрение стандарта NIST FIPS 204 — квантово-устойчивых цифровых подписей на решетках `crypto/mldsa` (Dilithium) в X.509 и TLS, поддержка полноценных generic-методов у структур.

## 🛠 Техническое устройство портала

Веб-учебник генерируется кастомным легковесным SSG-генератором на чистом Python, спроектированным по принципам простоты и надежности Unix:

```text
go-textbook/
├── sources/             # Единый источник правды (SSOT): 1413 Markdown-статей
├── builder/             # Движок генератора и инструменты QA
│   ├── build_all.py     # Главный оркестратор компиляции (флаги --all, --module)
│   ├── scanner.py       # Парсер источников, wikilinks-резолвер, канонизация путей
│   ├── converter.py     # AST-конвертер Markdown -> HTML5, Callouts, Mermaid, TOC
│   ├── template.py      # HTML5 каркас, адаптивные стили, живой поиск, KaTeX
│   ├── audit_all.py     # Сквозной QA-аудитор (ссылки, анкоры, кроссплатформенность)
│   └── colorize_mermaid.py # Семантическая раскраска Mermaid-диаграмм
├── dist/                # Готовый скомпилированный сайт (1414 HTML страниц + ассеты)
├── AGENTS.md            # Единый регламент и Single Source of Truth для AI-агентов
├── favicon.ico / .svg   # Иконки портала
└── README.md            # Данное руководство
```

### Преимущества архитектуры
* ⚡ **Высокая скорость:** Полная сборка всех 1413 статей с разбором AST, генерацией TOC, обработкой выносок и подсветкой кода занимает всего **~13 секунд**.
* 🛡 **Автоматический QA-аудитор (`audit_all.py`):** Проверяет 100% сгенерированных страниц на битые ссылки (0 broken links), валидность внутренних якорей и полную совместимость с файловыми системами всех ОС.

## 🚀 Как пользоваться порталом

### Для читателей и инженеров

#### Вариант 1: Мгновенный просмотр локально (Offline First — без установки чего-либо)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/UnrealTemplier/go-textbook.git
   cd go-textbook
   ```
2. Откройте файл `dist/index.html` в любом браузере:
   * **Linux:** `xdg-open dist/index.html`
   * **macOS:** `open dist/index.html`
   * **Windows:** двойной клик по `dist/index.html` или `start dist/index.html`

Всё работает прямо из коробки по протоколу `file:///`.

#### Вариант 2: Локальный веб-сервер
Если вы предпочитаете открывать портал через локальный веб-сервер:
```bash
python3 -m http.server 8080 -d dist
```
После чего перейдите в браузере по адресу: [http://localhost:8080](http://localhost:8080).

#### Вариант 3: Хостинг в сети
Директория `dist/` готова к развертыванию на любой статической платформе:
* **GitHub Pages:** укажите ветку `main` и папку `/dist`;
* **Nginx:** укажите `root /path/to/go-textbook/dist; index index.html;`.

---

### Для разработчиков и AI-агентов

Все правила разработки, редактуры и расширения энциклопедии зафиксированы в документе **[`AGENTS.md`](AGENTS.md)**. Он служит строгим контрактом для любых моделей ИИ и контрибьюторов.

#### Инженерный цикл внесения изменений:
1. **Правки вносятся только в `sources/`:** Категорически запрещено редактировать сгенерированный HTML в `dist/` вручную (он перезаписывается).
2. **Пересборка учебника:**
   * Собрать конкретный модуль для быстрой проверки:
     ```bash
     python3 builder/build_all.py --module 22
     ```
   * Собрать всю энциклопедию целиком:
     ```bash
     python3 builder/build_all.py --all
     ```
3. **Обязательный запуск сквозного QA-аудита:**
