## 0. Как читать документ

* **Обязательность.** «Должен», «обязан», «запрещено» — требование. «Можно» — свобода исполнителя. Других степеней нет.
* **Числа.** Числа о корпусе измерены на `go-textbook` при `HEAD bbb4b1f7` (после правок до А0 и удаления ретро-эффектов) и на данных `go-workout` в `go-workout/builder/`. Если рядом стоит пометка **«строит инструмент»**, число ориентировочное: в план, коммит или тест его не записывают, список страниц или мест строит инструмент проверки. Числа без этой пометки проверены и годятся как ожидаемое значение оракула.

* **Приоритет источников.** Директивы владельца (§ 2) → этот документ → `AGENTS.md` `go-textbook` (в части, не изменённой этим документом) → код. При противоречии документа и кода прав документ, но расхождение нужно показать владельцу.
* **Изменение решений.** Любое решение отсюда меняется только с согласия владельца, с записью в `html-textbook-engine-extraction-roadmap.md` (раздел «Изменения решений»).

### 1.3. Неизменные принципы (из `AGENTS.md` `go-textbook`, распространяются на движок)

1. **Offline First.** Сайт полностью работает по `file:///`, без сервера и без сети. Все пути относительные.
2. **Ноль CDN и сетевых запросов.** Шрифты, Prism, Mermaid 10.9.1, KaTeX поставляются локально.
3. **Зависимости сборки:** Python ≥ 3.11 (нужен `tomllib`) и **единственный сторонний пакет** `markdown>=3.10,<3.11`. Версия зафиксирована: расширения движка завязаны на внутренние регулярные выражения и приоритеты Python-Markdown 3.10. Остальное — стандартная библиотека: `tomllib`, `dataclasses`, `unittest`, `html.parser`, `hashlib`. Jinja2, Pydantic, pytest, Playwright, npm запрещены.
4. **Браузеры для проверок:** headless Firefox (как сейчас в `audit_all.py`). Для проверок `file://` из А3г дополнительно Chromium, запускается напрямую (`chromium --headless`), без Playwright.
5. **`dist/` воспроизводим:** полная сборка в чистый каталог побайтно совпадает с закоммиченным `dist/` `go-textbook`. На этом свойстве держатся все оракулы.
6. **Ручные правки `dist/` запрещены.**

### 1.4. Что вне объёма

* `emu-textbook` и его выноски и языки Prism (`[!timing]`, Verilog, Z80) не проектируются.
* Режим навигации `script` (сайдбар целиком из JS) не делается.
* Режим сканера `flat` и формат slug `{num:03d}-` не делаются (YAGNI, § 12).
* Полнотекстовый поиск не делается. Поиск остаётся поиском по названиям страниц.
* Сворачиваемые выноски (`[!x]-`/`[!x]+`) — низкий приоритет. В `go-workout` они не нужны (U6), в план А они не входят.
* Сохранение старых URL `go-workout` не требуется (U3).

### 4.2. Поставка и синхронизация ядра

1. **`engine/` в книге не редактируется.** Вся кастомизация — в `book.toml`, `book/overrides/`, `book/assets/`, `book/hooks.py`.
2. **`engine/VERSION`** — SemVer ядра. **`engine/.checksums.json`** — SHA-256 каждого файла ядра.
3. **`python -m engine.sync --from <путь | git-URL | tarball>`:**
   * сверяет `engine/` книги с `.checksums.json`. Если файлы правились локально, останавливается и показывает diff;
   * заменяет файлы ядра атомарно, **удаляет файлы, которых нет в новой версии**, обновляет `VERSION`;
   * делает один коммит `chore(engine): sync to vX.Y.Z`.
4. **Каждая сборка** сверяет контрольные суммы и при расхождении печатает предупреждение «`engine/` изменён локально: …».
5. **`CHANGELOG.md`:** у каждой версии пометка «меняет вывод: да/нет».
6. **Upstream.** На А0–А4 ядро живёт в `go-textbook/engine/`, и правки вносятся там. На А5 ядро публикуется в `html-textbook-engine`, и с этого момента upstream — `html-textbook-engine`. Исправление, найденное в книге, сначала вносится в движок, затем приходит в книгу через `engine.sync`. **Критерий А5:** после первого `engine.sync` в `go-textbook` `dist/` побайтно совпадает с тем, что был до синхронизации.
7. `git subtree` и `git submodule` не используются. Желающие могут подключить `engine/` через `git subtree`, но движок на это не рассчитывает.

### 4.3. Слои кастомизации

1. **Данные** — `book.toml` (§ 4.4).
2. **Переопределения** — `book/overrides/<путь как в engine/templates или engine/assets>`. Частичные шаблоны: `sidebar_header`, `article_header`, `index_hero`, `footer`. Стили и скрипты книги — `book/assets/extra.css`, `extra.js`.
3. **Хуки** — `book/hooks.py` с явным реестром: `transform_markdown(text, article)`, `render_callout(type, title, html)`, `page_context(article, ctx)`, `extra_audit_checks(dist)`.

Логотип — путь к SVG-файлу, а не SVG-строка в конфиге.

### 4.5. Сканер и модель контента

1. **Рекурсивное дерево произвольной глубины.** Узел: `{id (slug пути), title, number?, children, page?, is_index}`. Номер — метка отображения, а не идентичность. Для `go-textbook` пути и slug **побайтно совпадают** с текущими.
2. **Ошибки сборки вместо тихих потерь:** `.md` в корне `sources/`; файлы подраздела рядом с под-подкаталогами (сейчас отбрасываются); коллизия выходных путей после обрезки slug; два каталога без номера (сейчас оба становятся `module_num = 99`). В `go-textbook` ни один случай сейчас не срабатывает.
3. **`title_source = "h1"`:** заголовок страницы — первый H1, этот H1 убирается из тела. Если H1 нет — ошибка.
4. **Индексный файл каталога (U22).** Файл, имя которого совпадает с `index_file` (`0.`, `00.`, `000.` …), — заглавная страница своего каталога на любой глубине:
   * страница выводит H1 и текст файла, а **под ним список дочерних страниц** (номер и название — ссылкой). Пустой страница не бывает (у 288 разделов `go-workout` описания нет);
   * хлебные крошки: `Главная › Глава › Раздел › Задача`, все звенья — ссылки;
   * сайдбар: заголовок узла каталога — ссылка на заглавную страницу, шеврон раскрывает и сворачивает узел;
   * пагинация «назад/вперёд» включает заглавные страницы в порядке обхода дерева (`… → последняя задача раздела 1 → 00. О разделе (раздел 2) → первая задача раздела 2 → …`);
   * флаг `is_index = True`: страница **не входит в счётчики** («Задача 142 из 7 666» считает только задачи). Счётчик «Задача N из M» — **новый элемент UI** (в `go-textbook` его нет), выводится только при наличии индексных файлов.
5. **Оверлеи** (траектории `go-workout`): именованные списки глав. Проверка при сборке: каждая страница стоит в дереве ровно один раз, все номера из оверлеев существуют.

**Расширения Python-Markdown движка и приоритеты:**

| Расширение | Тип | Приоритет | Почему такой | Флаг |
|---|---|:-:|---|---|
| `fenced_code_block` (библиотека) | Preprocessor | 25 | штатный | — |
| `IndentedFencePreprocessor` | Preprocessor | **24** | после `fenced_code` и **выше `html_block` (20)**: ниже 20 строки HTML-кода (`<div class="x">`) уже спрятаны как сырой HTML и стали бы разметкой страницы | `indented_fences` |

| `MathInlineProcessor` | InlinePattern | **185** | после `backtick` (190), до `escape` (180) и `em_strong` | `math.protect` |
| `HeadingTreeprocessor` | Treeprocessor | **5** | в самом конце | всегда (активен только в основном вызове) |

**Правило для строчных препроцессоров:** они работают с Markdown, а не с готовым HTML. Готовый HTML (Mermaid, выноски) всегда прячется в плейсхолдеры **до** основного прохода. Правило «все строчные препроцессоры ниже 20» **неверно** (препроцессор оград обязан стоять на 24).

**Экранирование хвоста `#` (Е1, единое правило).** Во всех ATX-заголовках, которые разбирает Python-Markdown, хвост из `#`, приклеенный к непробельному символу (не к `\` и не к другому `#`), экранируется: `C#` → `C\#`. Выражение: `^(#{1,6}\s+.*[^\s#\\])(#+)\s*$` → `\1` + `\#` × длина хвоста. Закрывающая последовательность через пробел (`# Текст #`) не трогается. Применяется только вне кода. Слаг считается из **исходного** текста. Для H1/H5/H6 это уже работает в `builder/` (`e988b93d`), ядро переносит правило в А1. Для H2–H4 правило включается в А3е. В корпусе: H2–H4 — 1 место (модуль 17, «…PHP и C#»), H1 — 1 место (модуль 4, статья 4). В данных `go-workout` — 0.

#### 4.7.1. Сканер оград с отступом `scan_indented_fences`

* Открывающая ограда: `^(?P<indent>[ \t]+)(?P<fence>`{3,}|~{3,})[ ]*(?:\{?[. ]*(?P<lang>[\w#.+-]*)[ ]*\}?)?[ ]*$`. Поддерживаются `{ .go }` и языки `c++`, `c#`, `.go`.
* Контекст списка (`find_list_context`): от ограды вверх до первой непустой строки с отступом **меньше**, чем у ограды. Дальше вверх до строки с отступом не больше найденного: если это маркер `[-*+]` или `\d+\.`, то блок в списке. Если дошли до отступа 0 без маркера, то не в списке. Смотреть только на одну предыдущую строку запрещено (вход 9).
* Отступ ≥ 4 вне списка — обычный блок кода CommonMark, сканер его пропускает (вход 4).
* Закрывающая ограда: **тот же символ**, длина **не меньше** открывающей, отступ не больше отступа открывающей.
* Непустая строка с отступом меньше базового обрывает блок: незакрытая ограда, текст не захватывается, в логгер сборки уходит предупреждение `Unclosed fence starting at line N`. То же при конце файла.
* Строки кода: базовый отступ снимается; пустые строки остаются пустыми.
* **Одна функция** для маски и для препроцессора. Расхождение между ними — ошибка.

#### 4.7.2. Маска кода `UnifiedCodeLineMask`

* Строится **по тексту, который правит потребитель, в момент правки, на каждую единицу**:

#### 4.7.4. Препроцессор списков (U17, А3л)

Эталонного кода нет: прототип рецензента грубый и служил только для проверки оград. Препроцессор пишется в А2 по правилам ниже и проверяется оракулом А3л (§ 6.4).

* Приоритет 19. Работает с Markdown (HTML выносок и Mermaid к этому моменту — плейсхолдеры).
* **Правило Obsidian / CommonMark:** список может начинаться сразу после строки абзаца, без пустой строки. Перед первым пунктом, идущим за строкой текста, вставляется пустая строка.
* **Вложенность:** отступ пункта 2–3 пробела относительно родителя (Obsidian) переводится в отступ Python-Markdown (4 на уровень). Содержимое пункта (продолжение текста, плейсхолдеры оград) переводится в те же координаты.
* **Возврат на внешний уровень:** перед пунктом вставляется пустая строка, если текущий блок (от последней пустой строки) начался с более глубокого отступа. Иначе Python-Markdown склеит пункт `2.` с абзацем вложенного пункта или с текстом после кода (входы 16, 17).

* Работает и в телах выносок (там 2 607 псевдопунктов).

Обычные цитаты (не выноски) обрабатываются рекурсивно без префикса `>`; неизменённая цитата остаётся побайтно прежней. Оба правила добавлены по итогам оракула А3л (roadmap § 7).

#### 4.7.5. Защита формул `MathInlineProcessor` (А3и, Б)

### 4.9. Клиентский рантайм `window.__BOOK__` (А3ж)

Подсистема ретро-эффектов удалена владельцем 2026-10-09 (`2862bb04`), поэтому рантайм отвечает только за тему.

Данные генерирует Python: префикс — из `book.toml`, темы и тема по умолчанию — из `manifest.json`.
* **Ключи `go-textbook` не меняются:** `go_encyclopedia_theme`, `go_encyclopedia_sidebar_width`. Оба строятся через `storageKey`. Ключи `go_encyclopedia_retro_effects*` у старых посетителей остаются в хранилище и не читаются.
* Все обращения к `localStorage` — в `try/catch`.
* **Смешанные версии (Е2).** Запасного объекта нет. В обработчике `DOMContentLoaded` порядок вызовов § 6 `AGENTS.md` сохраняется, и проверка оборачивает **только** переключатель темы:

  ```javascript
  document.addEventListener('DOMContentLoaded', function () {
    saveMermaidSources(); initMermaid(); initKaTeX(); initActionDelegation();
    initSidebarResize(); initSidebarFilter(); initSidebarCentering();
    initScrollProgress(); initMobileMenu(); initGlobalSearch();
  ```

  Выходить из обработчика (`return`) запрещено: старый HTML с новым `main.js` потерял бы Mermaid, KaTeX, копирование, сайдбар и поиск. Отдельная IIFE запрещена: она изменила бы порядок инициализации.   2. сохранённая допустимая тема → она же уже в inline-скрипте (проверять **перезагрузкой той же страницы**: в Firefox у каждого `file://`-файла своё хранилище);
  3. неизвестное значение темы → тема по умолчанию;
  4. недоступное хранилище (исключение при обращении) → тема по умолчанию, 0 исключений;

### А.1. Сканер оград и маска (`engine/converter/code_mask.py`)

```python
import re
from bisect import bisect_right
from typing import List, Dict, Any, Set, Optional, Callable
import markdown
from markdown.extensions.fenced_code import FencedBlockPreprocessor


def find_list_context(lines: List[str], fence_idx: int, fence_indent_len: int) -> tuple[bool, int]:
    """Вверх до первой непустой строки с отступом меньше, чем у ограды; затем — до маркера списка."""
    k = fence_idx - 1
    while k >= 0:
        line = lines[k]
        if not line.strip():
            k -= 1
            continue
        cur_indent = len(line) - len(line.lstrip(' '))
        if cur_indent < fence_indent_len:
            check_k = k
            while check_k >= 0:
                chk_line = lines[check_k]
                chk_stripped = chk_line.strip()
                if not chk_stripped:
                    check_k -= 1
                    continue
                chk_indent = len(chk_line) - len(chk_line.lstrip(' '))
                if chk_indent <= cur_indent:
                    if re.match(r'^(?:[-*+]|\d+\.)\s+', chk_stripped):
                        return True, cur_indent
                    if chk_indent == 0:
                        return False, 0
                check_k -= 1
            return False, 0
        k -= 1
    return False, 0


OPEN_FENCE_RE = re.compile(
    r'^(?P<indent>[ \t]+)(?P<fence>`{3,}|~{3,})[ ]*(?:\{?[. ]*(?P<lang>[\w#.+-]*)[ ]*\}?)?[ ]*$')
CLOSE_FENCE_RE = re.compile(r'^(?P<indent>[ \t]*)(?P<fence>`{3,}|~{3,})[ ]*$')


def scan_indented_fences(lines: List[str],
                         warn_func: Optional[Callable[[str], None]] = None) -> List[Dict[str, Any]]:
    """Единый сканер оград с отступом: им пользуются и маска, и препроцессор."""
    blocks = []
    i, n = 0, len(lines)
    while i < n:
        m = OPEN_FENCE_RE.match(lines[i])
        if m:
            open_indent = m.group('indent')
            fence_str = m.group('fence')
            fence_char, fence_len = fence_str[0], len(fence_str)
            lang = m.group('lang') or ''
            indent_len = len(open_indent)
            in_list, target_indent = find_list_context(lines, i, indent_len)
            if indent_len >= 4 and not in_list:      # обычный блок кода CommonMark
                i += 1
                continue
            code_lines, j, closed = [], i + 1, False
            while j < n:
                cur_line = lines[j]
                stripped = cur_line.strip()
                if stripped.startswith(fence_char * fence_len):
                    cm = CLOSE_FENCE_RE.match(cur_line)
                    if cm and cm.group('fence')[0] == fence_char \
                            and len(cm.group('fence')) >= fence_len \
                            and len(cm.group('indent')) <= indent_len:
                        closed = True
                        break
                cur_indent_len = len(cur_line) - len(cur_line.lstrip(' '))
                if stripped and cur_indent_len < indent_len:   # обрыв: незакрытая ограда
                    if warn_func:
                        warn_func(f"Unclosed fence starting at line {i + 1}")
                    break
                code_lines.append(cur_line)
                j += 1
            if closed:
                clean = []
                for c in code_lines:
                    if c.startswith(open_indent):
                        clean.append(c[indent_len:])
                    elif not c.strip():
                        clean.append('')
                    else:
                        clean.append(c.lstrip(' '))
                blocks.append({'start_line': i, 'end_line': j, 'open_indent': open_indent,
                               'in_list': in_list, 'target_indent': target_indent,
                               'lang': lang, 'code_lines': clean})
                i = j + 1
                continue
            if warn_func and j == n:
                warn_func(f"Unclosed fence starting at line {i + 1}")
        i += 1
    return blocks


class UnifiedCodeLineMask:
    """Номера строк (с 0) текста единицы, которые Python-Markdown выведет кодом."""

    def __init__(self, target_text: str, md: markdown.Markdown, include_indented: bool):
        # include_indented обязан быть равен флагу indented_fences конфигурации
        raw_lines = target_text.split('\n')
        self.num_lines = len(raw_lines)
        norm_lines = md.preprocessors['normalize_whitespace'].run(raw_lines)
        norm_str = '\n'.join(norm_lines)
        starts = [0]
        for line in norm_lines:
            starts.append(starts[-1] + len(line) + 1)
        self.lines: Set[int] = set()
        for m in FencedBlockPreprocessor.FENCED_BLOCK_RE.finditer(norm_str):
            first = bisect_right(starts, m.start()) - 1
            last = bisect_right(starts, m.end() - 1) - 1
            self.lines.update(l for l in range(first, last + 1) if l < self.num_lines)
        if include_indented:
            for b in scan_indented_fences(norm_lines):
                self.lines.update(l for l in range(b['start_line'], b['end_line'] + 1)
                                  if l < self.num_lines)

    def is_line_in_code(self, line_num: int) -> bool:
        return line_num in self.lines
```

### А.2. Препроцессор оград (`engine/converter/indented_fence.py`)

```python
from markdown.preprocessors import Preprocessor
from .code_mask import scan_indented_fences


class IndentedFencePreprocessor(Preprocessor):
    """Приоритет 24: после fenced_code_block (25), выше html_block (20) и списков (19)."""

    def __init__(self, md, warn_func=None):
        super().__init__(md)
        self.warn = warn_func or (lambda msg: None)

    @staticmethod
    def _escape_code(text: str) -> str:
        return text.replace('&', '&amp;').replace('<', '&lt;').replace('>', '&gt;').replace('"', '&quot;')

    def run(self, lines: list[str]) -> list[str]:
        blocks = {b['start_line']: b for b in scan_indented_fences(lines, self.warn)}
        out, i, n = [], 0, len(lines)
        while i < n:
            b = blocks.get(i)
            if b is None:
                out.append(lines[i])
                i += 1
                continue
            code = '\n'.join(b['code_lines']) + '\n' if b['code_lines'] else ''   # байты как у fenced_code
            lang = f' class="language-{b["lang"]}"' if b['lang'] else ''
            ph = self.md.htmlStash.store(f'<pre><code{lang}>{self._escape_code(code)}</code></pre>')
            if out and out[-1].strip():
                out.append('')                      # плейсхолдер — отдельный блок
            out.append(b['open_indent'] + ph)       # отступ ограды; перевод отступов — препроцессор списков
            nxt = b['end_line'] + 1
            if nxt < n and lines[nxt].strip():
                out.append('')
            i = nxt
        return out
```

### А.3. Выноски-плейсхолдеры (`engine/converter/callouts.py`)

```python
import re
from typing import Dict, List, Tuple
from .code_mask import UnifiedCodeLineMask

CALLOUT_START_RE = re.compile(r"^>\s*\[!([a-zA-Z0-9_-]+)\]\s*(.*)$")


class CalloutExtractor:
    def __init__(self, converter):
        self.converter = converter    # даёт md, config, transform_wikilinks, get_callout_config

    def extract_callouts(self, text: str, placeholders: Dict[str, str], article) -> str:
        lines = text.splitlines()
        out: List[str] = []
        in_callout, c_type, c_title, body, idx = False, "note", "", [], 0

        def flush():
            nonlocal idx, body
            ph, html_box = self._render(idx, c_type, c_title, body, article)
            placeholders[ph] = html_box
            out.append(f"\n\n{ph}\n\n")
            idx += 1
            body = []

        i = 0
        while i < len(lines):
            line = lines[i]
            m = CALLOUT_START_RE.match(line)
            if m:
                if in_callout:
                    flush()
                in_callout, c_type, c_title = True, m.group(1).lower(), m.group(2).strip()
                i += 1
                continue
            if in_callout:
                if line.startswith(">"):
                    content = line[1:]
                    body.append(content[1:] if content.startswith(" ") else content)
                    i += 1
                    continue
                if line.strip() == "" and i + 1 < len(lines) and lines[i + 1].startswith(">"):
                    body.append("")
                    i += 1
                    continue
                flush()
                in_callout = False
                if line.strip() != "":
                    out.append(line)
                i += 1
                continue
            out.append(line)
            i += 1
        if in_callout:
            flush()
        return "\n".join(out)

    def _render(self, idx: int, c_type: str, c_title: str, body_lines: List[str], article) -> Tuple[str, str]:
        ph = f"<!--CALLOUT_PLACEHOLDER_{idx}-->"
        body_text = "\n".join(body_lines)
        conv = self.converter
        mask = UnifiedCodeLineMask(body_text, conv.md, include_indented=conv.config.markdown.indented_fences)
        body_text = conv.transform_wikilinks(body_text, article, mask=mask)
        inner_html = conv.md.convert(body_text)       # heading_slugs здесь None: HeadingTreeprocessor пассивен
        conv.md.reset()
        cfg = conv.get_callout_config(c_type, c_title)  # алиасы, иконки, interview_heuristic — как сейчас
        # HTML <aside> обязан побайтно совпадать с текущим _transform_callouts
        return ph, cfg["render"](inner_html)
```

Порядок в `convert_article`: после `md.convert` подставить плейсхолдеры Mermaid и выносок, затем `_wrap_tables`, затем `_enhance_code_blocks`. Клише на шаге 1 применяются по маске к тексту статьи и к телу каждой выноски.

### А.4. Заголовки (`engine/converter/headings.py`)

```python
import re
from markdown.treeprocessors import Treeprocessor

TRAILING_HASH_RE = re.compile(r"^(#{1,6}\s+.*[^\s#\\])(#+)\s*$")


def escape_trailing_hashes(line: str) -> str:
    """'## … C#' -> '## … C\\#': иначе Python-Markdown срежет '#' как закрывающую последовательность."""
    return TRAILING_HASH_RE.sub(lambda m: m.group(1) + "\\#" * len(m.group(2)), line)


class HeadingTreeprocessor(Treeprocessor):
    """Приоритет 5. Ставит id H2–H4 по списку якорей TOC; только в основном вызове."""

    def run(self, root):
        slugs = getattr(self.md, 'heading_slugs', None)
        if slugs is None:              # тело выноски или другой вспомогательный вызов
            return
        headings = [el for el in root.iter() if el.tag in ('h2', 'h3', 'h4')]
        if len(headings) != len(slugs):
            raise RuntimeError(f"HeadingTreeprocessor: {len(headings)} headings in AST, "
                               f"{len(slugs)} in TOC")
        for h, slug in zip(headings, slugs):
            h.set('id', slug)
```

Использование в основном вызове:

```python
self.md.heading_slugs = [item["anchor"] for item in toc]
try:
    html_content = self.md.convert(processed_text)
finally:
    self.md.heading_slugs = None
    self.md.reset()
```

Слаг считается из **исходного** текста заголовка (до `escape_trailing_hashes`). `escape_trailing_hashes` применяется к строкам-заголовкам вне кода. Оракул видимого текста — § 6.4, А3е (не `verify_heading_oracle` из ответа №14: тот отбрасывал атрибуты и сравнивал разметку).

### А.5. Защита формул (`engine/converter/math_protect.py`)

```python
import re
import html
import markdown
import markdown.util as util
from markdown.inlinepatterns import InlineProcessor


class MathInlineProcessor(InlineProcessor):
    """Приоритет 185: после backtick (190), до escape (180) и em_strong."""

    def handleMatch(self, m, data):
        raw = m.group(0)
        if util.INLINE_PLACEHOLDER_PREFIX in raw or '\x02' in raw or '\x03' in raw:
            return None, None, None          # внутри формулы уже обработанный inline-код
        return self.md.htmlStash.store(html.escape(raw)), m.start(0), m.end(0)


class MathProtectExtension(markdown.Extension):
    def __init__(self, delimiters: list[dict], protect: list[str]):
        super().__init__()
        by_left = {d["left"]: d for d in delimiters}
        missing = [p for p in protect if p not in by_left]
        if missing:
            raise ValueError(f"book.toml: [math].protect {missing} отсутствуют в [math].delimiters")
        self.pairs = [by_left[p] for p in protect]

    def extendMarkdown(self, md):
        for idx, d in enumerate(self.pairs):
            pattern = r"(?<!\\)" + re.escape(d["left"]) + r"(.+?)" + re.escape(d["right"])
            md.inlinePatterns.register(MathInlineProcessor(pattern, md), f"math_protect_{idx}", 185)
```

### А.7. URL ассета (Е3, `engine/template.py`)

```python
import hashlib
from pathlib import Path

_ASSET_HASHES: dict[str, str] = {}


def get_asset_url(rel_asset_path: str, rel_root: str, dist_dir: Path) -> str:
    """rel_root = "../" * depth страницы. Хэш — от файла, уже записанного в dist/, один раз за сборку."""
    h = _ASSET_HASHES.get(rel_asset_path)
    if h is None:
        target = dist_dir / rel_asset_path
        if not target.exists():
            raise FileNotFoundError(f"asset not found in dist: {target}")
        h = _ASSET_HASHES[rel_asset_path] = hashlib.sha256(target.read_bytes()).hexdigest()[:10]
    return f"{rel_root}{rel_asset_path}?v={h}"
```

Кэш сбрасывается в начале каждой сборки. Ассеты пишутся в `dist/` до генерации страниц, `search-data.js` и `nav-data.js` — до первой страницы, которая на них ссылается.
