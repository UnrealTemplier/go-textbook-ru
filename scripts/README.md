# Скрипты запуска go-textbook

**Нужен один запуск — `REBUILD_ALL`.** Он ставит зависимости, пересобирает `dist/` с нуля (строго), проверяет сайт строгим аудитом (с рантаймом KaTeX и Mermaid в Firefox), запускает тесты ядра и книги, проверяет реестр двойных H1. `dist/` в Git не хранится (локальная сборка). В конце печатает итог.

- Windows: двойной щелчок по `REBUILD_ALL.bat`.
- Linux: двойной щелчок по `REBUILD_ALL.sh`.

Двойной щелчок открывает новое окно терминала по умолчанию (в KDE — из настроек «Терминал по умолчанию»), скрипт выполняется в нём, и окно остаётся открытым, пока вы его не закроете. Запуск из уже открытого терминала работает так же, только без нового окна. Полная пересборка занимает несколько минут: самая долгая часть — рантайм-проверка в Firefox.

Для Linux файл должен быть исполняемым (в git это уже сохранено). Если файловый менеджер открывает `.sh` в редакторе, а не запускает его, выберите запуск исполняемого файла в его настройках.

## Остальные команды

Каждая команда — отдельный скрипт, их не нужно запускать вручную, если хватает `REBUILD_ALL`:

- `windows/<имя>.bat` — Windows;
- `linux/<имя>.sh` — Linux и macOS.

Скрипты сами переходят в корень репозитория, поэтому запускаются из любого каталога и двойным щелчком. Аргументы передаются команде как есть (`linux/build.sh --dist /tmp/site`). `.bat`-скрипты при двойном щелчке остаются открытыми до закрытия окна; из меню — нет.

**Меню:** `windows/menu.bat` / `linux/menu.sh` — список всех команд; выберите номер, после выполнения меню откроется снова.

Python: в Linux — `python3` (или `python`), в Windows — `py -3` (или `python`). Нужен Python ≥ 3.11 и `pip install -r requirements.txt`.

| Скрипт | Что делает |
|---|---|
| `check` | Всё перед коммитом: строгая сборка, строгий аудит, тесты |
| `build` | Полная сборка сайта в dist/ |
| `build-strict` | Полная сборка; предупреждения сборки — ошибки |
| `build-clean` | Чистая пересборка: удалить dist/ и собрать заново (убирает страницы-сироты) |
| `build-module` | Сборка одного модуля (номер — аргументом или по запросу) |
| `audit` | Аудит dist/: ссылки, якоря, имена файлов, ассеты, offline, диаграммы |
| `audit-strict` | Аудит + предупреждения сборки как ошибки |
| `audit-full` | Полный аудит: --strict и рантайм KaTeX/Mermaid в Firefox (несколько минут) |
| `audit-no-browser` | Аудит без Firefox (без рантайм-разбора диаграмм) |
| `runtime-projection` | Что браузер нарисовал на каждой странице (формулы, диаграммы, ошибки JS), Firefox |
| `tests` | Тесты ядра и книжные тесты (после пересборки dist/) |
| `engine-sync` | Обновить engine/ из репозитория движка (ENGINE_DIR, по умолчанию ../html-textbook-engine); делает коммит |
| `open-site` | Открыть dist/index.html в браузере |
| `audit-write-baseline` | Перезаписать базу известных дефектов book/audit-baseline.json (после исправления ссылок или формул) |
| `build-pilot` | Пилотная сборка: первые 15 статей модуля 1 (~1 с) |
| `title-duplicates` | Проверить реестр двойных H1 fact-checks/title-duplicates.md (код 1, если устарел) |
| `title-duplicates-write` | Перегенерировать реестр двойных H1 |
| `verify-editorial` | Проверка авторской вычитки статьи относительно HEAD (путь — аргументом или по запросу) |

`ENGINE_DIR` — путь к репозиторию движка для `engine-sync` (по умолчанию соседний каталог `../html-textbook-engine`). Общая часть — `linux/_lib.sh` / `windows/_lib.bat`; `REBUILD_ALL` — самостоятельный файл, без неё.
